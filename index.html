Two tools for OCR GCSE Computer Science. Both run entirely in the browser, with nothing to install and no account to make: the Python is really executed, one step at a time if you want.

Python Blocks

Drag blocks together, get real Python

  • Every block is a piece of J277 Python: selection, iteration, arrays, sub programs, file handling
  • The Python appears as you build, and runs for real
  • Built-in help explains each idea next to the OCR reference language
  • Reading and writing text files works, without touching the real computer

Flowcharts

Python and flowchart, kept in step

  • Draw a flowchart and get Python, or type Python and get the flowchart
  • Step through one shape at a time, watching the variables change
  • Builds a trace table as it goes, like the ones in the exam
  • Shapes can be labelled in exam reference language, and saved as a picture

About the offline copies

The ordinary pages fetch Blockly and Python from the internet the first time they are used. The offline copies have both built in, so they work with the network switched off: save one to a memory stick or a shared drive, open it in any browser, and everything still runs.

Work is saved in the browser it was made in, so it stays on that computer. Use Copy code or Save picture to take work somewhere else.
